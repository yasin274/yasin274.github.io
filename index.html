J.A.R.V.I.S

Голосовой ассистент для Windows

Фоновый помощник в системном трее: строка запуска по Alt+Space, управление системой голосом и текстом, объяснение кода из буфера обмена через локальную модель Qwen в Ollama. Распознавание речи и wake-word «Джарвис» работают офлайн на Vosk, ответы озвучиваются через Windows SAPI.

PassBox

Менеджер паролей

Десктопное хранилище паролей с шифрованием AES-256-GCM: ключ выводится из мастер-пароля через PBKDF2 с 600 000 итераций. К записям крепятся вложения, буфер обмена очищается через 30 секунд, а доступ можно восстановить по резервной фразе из 16 слов.
