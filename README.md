# Портфолио — yasin274.github.io

Персональный сайт-портфолио: проекты, стек, контакты.

**🔗 [yasin274.github.io](https://yasin274.github.io/)**

## Что внутри

- Тёмный tech-дизайн, собственная палитра на CSS-переменных
- Карточки проектов с фильтром по типу (веб / десктоп)
- Плавное появление секций при скролле (IntersectionObserver)
- Полностью адаптивно: от 375px до широких экранов
- Локальные шрифты — ноль внешних запросов, ноль зависимостей, без сборки
- Работает и без JavaScript: контент остаётся видимым

## Стек

`HTML5` · `CSS3` (Grid, Flexbox, переменные) · `Vanilla JavaScript ES6+`

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8378
```

## Структура

```
portfolio/
├── index.html   # разметка и контент проектов
├── style.css    # оформление
├── script.js    # фильтры, анимации, sticky-навигация
└── fonts/       # локальные шрифты (Orbitron, Exo 2, JetBrains Mono — SIL OFL)
```
